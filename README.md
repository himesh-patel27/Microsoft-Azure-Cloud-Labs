# Azure Cloud Security Labs

This repository contains selected hands-on Microsoft Azure labs completed as part of my Cybersecurity graduate certificate coursework. I cleaned up the original assignment documentation into shorter project READMEs and retained selected screenshots captured while the environments were active.

## Labs

| Lab | Focus |
| --- | --- |
| [Azure Virtual Network and Virtual Machine](01-Azure-Virtual-Network-and-VM/) | Virtual networking, VM deployment, and connection verification |
| [Azure PowerShell and CLI Practice](02-Azure-PowerShell-and-CLI/) | PowerShell, Azure modules, CLI, and command-line administration |
| [Azure Recovery Services and Backup](03-Azure-Recovery-Services-and-Backup/) | Recovery Services Vault and Azure Backup |
| [Azure Custom VM Image with PowerShell](04-Azure-Custom-VM-Image-with-PowerShell/) | Windows Server, PowerShell, Hyper-V, and custom Azure image workflow |

## About the Environments
These were guided college labs rather than production environments. The Azure resources were temporary/student or free-tier resources and were decommissioned after the labs were completed to avoid ongoing cloud charges. The screenshots in each folder were captured from the original completed assignments and provide evidence of the work performed at the time.

## Repository Purpose
I use this repository to document practical experience with Azure infrastructure, administration, PowerShell, virtual machines, networking, backup/recovery, and image management.
